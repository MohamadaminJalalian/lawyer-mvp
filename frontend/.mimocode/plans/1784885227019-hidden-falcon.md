# Backend Integration Plan — Real API at `http://localhost:5000`

## Overview
Replace mock API routes with calls to a real backend at `http://localhost:5000`. The backend uses:
- **Auth paths**: `/auth/login`, `/auth/logout`, `/auth/me` (no `/api` prefix)
- **Dashboard path**: `/dashboard/stats` (no `/api` prefix)
- **Auth mechanism**: HttpOnly cookie (same as current mock)

---

## Step 1: Create Environment Variable File

**Create** `.env.local`:
```
NEXT_PUBLIC_API_BASE_URL=http://localhost:5000
```

---

## Step 2: Add Base URL to API Client

**Modify** `src/lib/api-client.ts`:
- Read `NEXT_PUBLIC_API_BASE_URL` from `process.env`
- Prepend base URL to all requests (so `/auth/login` becomes `http://localhost:5000/auth/login`)
- Keep `credentials: "include"` for cookie-based auth

---

## Step 3: Update Auth API Calls

**Modify** `src/features/auth/api/auth.api.ts`:
- Change URLs from `/api/auth/login` → `/auth/login`, `/api/auth/logout` → `/auth/logout`, `/api/auth/me` → `/auth/me`
- The apiClient base URL will handle the full URL

---

## Step 4: Update Dashboard Page

**Modify** `src/app/(protected)/page.tsx`:
- Replace raw `fetch("/api/dashboard/stats")` with `apiClient.get("/dashboard/stats")`
- This ensures consistent 401 handling and error handling

---

## Step 5: Add CORS Proxy via Next.js Rewrites

**Modify** `next.config.ts`:
- Add rewrites to proxy frontend `/api/*` → backend `http://localhost:5000/*`
- This avoids CORS issues during development
- Alternatively, if backend handles CORS, this step can be skipped

---

## Step 6: Delete Mock API Routes

**Delete** these files (no longer needed):
- `src/app/api/auth/login/route.ts`
- `src/app/api/auth/logout/route.ts`
- `src/app/api/auth/me/route.ts`

**Delete** mock data files (no longer needed by routes):
