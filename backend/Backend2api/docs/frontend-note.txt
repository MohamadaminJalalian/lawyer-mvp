سلام

فایل اصلی برای پیاده‌سازی فرانت‌اند در مسیر زیر قرار دارد:

docs/api-contract.json

نسخه HTML مستندات API برای تبدیل به PDF در مسیر زیر قرار دارد:

docs/api-contract.html

Base URL:

http://localhost:3000/api/v1

Authentication:

تمام APIها به‌جز Login نیاز به JWT دارند.

Header موردنیاز:

Authorization: Bearer <token>

نکته مهم:

تمام endpointها، request bodyها، responseها، roleها و error format باید دقیقاً بر اساس فایل api-contract.json پیاده‌سازی شوند.

نقش‌ها:

ADMIN:
دسترسی کامل شامل بایگانی پرونده

STAFF:
دسترسی به مشاهده، ثبت و ویرایش
بدون دسترسی به بایگانی پرونده
